# NMM Core Values

Three values govern every page, feature, and build decision. Nothing ships
unless it clears all three. They apply to the entire dashboard — traffic,
product, and experience — not any single page.

## A — Authority (traffic + citation)

- Every figure dated, sourced, and linked to its methodology.
- Every page answers a real search query (title, meta, canonical, OG).
- Any page showing an index or a number offers a "cite this" line.
- No orphan pages — everything links somewhere relevant.

## B — Value (a decision, not data)

- Every page answers a question a carrier actually has — "what's my floor,"
  "where's the cheapest fuel," "which crossing" — never just "here's data."
- Numbers carry a "what it means / what to do with it" line.
- Cost and floor framing run through everything.

## C — Convenience (use, not browse)

- Mobile-first and fast.
- No login, no signup — that's the headline, not a footnote.
- The answer first, detail below. One screen where possible.
- Push (the newsletter) as the default, so the reader never has to remember.

## The test before anything ships

Does it help a carrier decide — in five seconds, on a phone, without logging
in — and is every number dated and citeable? If not, it doesn't ship yet.
